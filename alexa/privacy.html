Our Household Board privacy policy

Last updated: September 30, 2026

Family Board stores the four-word codes a user supplies under a one-way hash of Amazon's skill-specific user identifier. Codes select a board but are not included in the published skill.

A board can contain names, events, chores, meals, lists, and private calendar-feed URLs. Calendar URLs are hidden from shared users. Calendar data is requested only to display the connected board. Data is not sold or used for advertising.

The Echo widget stores only the selected board name, next event summary, open-chore count, and dinner text in Alexa's on-device Data Store.

Saying “forget this board” removes the selected code from Alexa. Saying “forget all boards” removes every code saved for that Alexa user.
